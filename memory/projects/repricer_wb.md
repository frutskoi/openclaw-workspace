### Меню «Репрайсер»
1. Загрузить данные с ВБ → `loadWBData()` — ТОЛЬКО ВРУЧНУЮ
2. Получить цены по API ВБ → `getWbPrices()` — колонки M, N, O
3. Парсить цены с сайта ВБ → `parsePricesFromWbSite()` — колонки J, K
4. Рассчитать цены → `calculatePricesForUpload()`
5. Загрузить цены на ВБ → `uploadPricesToWb()`

**Авто-цикл (`runFullCycle`):** шаги 2→3→4→5 (БЕЗ загрузки товаров)
- Кнопки: «раз в 30 мин», «раз в 1 час», «Остановить»
- Триггеры через `ScriptApp`

### Правила репрайсера
1. Минимальная цена держится со скидкой продавца
2. Если товар при минимальной цене проходит в акцию — добавить
3. Исключить авто-добавление в акцию «ВБ бессрочно»
4. Передаваемая цена = до скидки продавца
5. Минимальная цена и цена для акций = со скидкой продавца

### API детали
- Цены API: `discounts-prices-api.wildberries.ru/api/v2/list/goods/filter`
  - M: цена до скидки (рубли), O: скидка (discount/100), P: M × (1−N)
- Парсинг сайта: `wildberries.ru/__internal/card/cards/v4/detail` (без токена)
  - J/K: client price, R: СПП = 1 − (client / (basic × (1−discount)))
  - Батчи по 20 nmId, ретраи при 429/5xx
  - СПП пишется в лист «СПП История»

⚠️ С сервера WB блокирует запросы (антиспам) — работает только из Google Apps Script.

## Решения
- Рабочий эндпоинт парсинга: `wildberries.ru/__internal/card/cards/v4/detail` (card.wb.ru = 404, u-search = пусто)
- Загрузка товаров только вручную (во избежание перезаписи)
- **FBW остатки**: `seller-analytics-api.wildberries.ru/api/analytics/v1/stocks-report/wb-warehouses` (POST с брендами). Ответ: `{"data":{"items":[{nmId, warehouseId, quantity, ...}]}}`. НЕ `analytics-api` (старый домен, не работает).
- FBS остатки: `marketplace-api.wildberries.ru/api/v3/stocks/{warehouseId}` (POST по штрихкодам)
- Content API `cards/list` НЕ содержит поле `stocks`
