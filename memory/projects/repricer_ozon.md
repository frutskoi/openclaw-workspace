### Меню «🟣 Репрайсер Ozon»
1. Загрузить товары → `loadOzonProducts()`
2. Получить цены (API) → `getOzonPrices()`
3. Парсить цены с сайта → `parseOzonSitePrices()`
4. Рассчитать цены → `calculatePrices()`
5. Загрузить цены на Ozon → `uploadPrices()`
- 📊 Полный цикл (1→2→3→4) → `fullCycle()`

### Алгоритм расчёта
1. Целевая = РРЦ (если задана) или текущая цена продавца
2. Если целевая < минимальная → целевая = минимальная
3. Округление до целого
4. Проверка эластичного бустинга → TRUE/FALSE
