### Меню "🟣 Репрайсер Ozon"
1. Загрузить товары → `loadOzonProducts()`
2. Получить цены (API) → `getOzonPrices()`
3. Парсить цены с сайта (Москва) → `parseOzonSitePrices()`
4. Рассчитать цены → `calculatePrices()`
5. Загрузить цены на Ozon → `uploadPrices()`
- 📊 Полный цикл (1→2→3→4) → `fullCycle()`

### Функции Apps Script
- `onOpen()` — создаёт меню
- `loadOzonProducts()` — загрузка товаров через /v3/product/list + /v2/product/info
- `getOzonPrices()` — цены продавца через /v5/product/info/prices
- `parseOzonSitePrices()` — парсинг цен с сайта Ozon (регион Москва, X-O3-Region-Id: 1)
- `calculatePrices()` — расчёт цены + проверка эластичного бустинга
- `getElasticBoostActions()` — получение списка акций бустинга через /v1/actions/list
- `checkProductInBoost()` — проверка участия товара через /v1/actions/candidates
- `uploadPrices()` — загрузка цен через /v1/product/import/prices
- `fullCycle()` — последовательный запуск 1→2→3→4

### Алгоритм расчёта
1. Целевая = РРЦ (если задана) или текущая цена продавца
2. Если целевая < минимальная → целевая = минимальная
3. Округление до целого
4. Проверка эластичного бустинга → TRUE/FALSE в колонке O
