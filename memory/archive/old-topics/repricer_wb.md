### Скрипт "Получить цены по API ВБ" (getWbPrices)
- Эндпоинт: GET `discounts-prices-api.wildberries.ru/api/v2/list/goods/filter`
- M (13): Цена до скидки продавца (рубли, без деления)
- N (14): Скидка продавца (десятичная дробь, discount/100)
- O (15): Цена со скидкой = M * (1 - N), Math.round()
- API возвращает цены в рублях, скидку в целых %

### Скрипт "Парсить цены с сайта ВБ" (parsePricesFromWbSite)
- Эндпоинт: `wildberries.ru/__internal/card/cards/v4/detail` (без токена!)
- J (10): client price с сайта (цена без кошелька)
- K (11): client price (пока та же)
- R (18): СПП = 1 - (client / (basic * (1 - discount)))
- Батчи по 20 nmId, ретраи при 429/5xx
- Скидка продавца берётся из discounts-prices-api или колонки N
- СПП записывается в лист "СПП История" (каждый запуск = новая колонка с датой)

### API данные (структура ответа)
- Root: `discount` (int %), `clubDiscount`, `nmID`, `vendorCode`, `sizes`
- sizes[0]: `price` (копейки), `discountedPrice` (копейки), `clubDiscountedPrice` (копейки)
