# Marketplace Manager — Wildberries + Ozon

Управление процессами на обоих маркетплейсах: единая точка входа для отчётов, юнитки, ОПиУ, цен и рекламы. Сам не ходит в API напрямую — делегирует профильным скиллам.

## Когда
Любая задача про WB или Ozon: «сводка по продажам», «ОПиУ за месяц», «юнитка», «проверь цены/рекламу», «что с остатками», «сколько заработали». Также когда задача упоминает оба маркетплейса сразу.

## Диспетчеризация

1. Определи, какие площадки и процессы затронуты.
2. Для деталей API читай профильный скилл и следуй его правилам:
   - WB: статистика, карточки, цены, реклама, ОПиУ → `wildberries-api` (rate-limit 3s+, токен в Настройки!B2 таблицы `1KZIFWQ61LUS17LpJTvemSX4jnjZJqB5hjl8E9w9a8fE`)
   - Ozon продавец: комиссии, юнитка, финансы → `ozon-seller-api` (Client-Id 959359, ключ в Настройки!C3 таблицы `1VUf_ryMnXuTkD7PBBfRu36fYScwPQtXDu75Dx_iyJgk`)
   - Ozon реклама: расходы, ДРР → `ozon-performance-api`
3. Независимые площадки можно опрашивать параллельно, но лимиты внутри каждой соблюдать строго.

## Стандартные процессы

### Ежедневная сводка (по запросу «как продажи»)
- WB: `/api/v1/supplier/sales?dateFrom=<7дн назад>&flag=1`, `/api/v1/supplier/orders` — выручка, заказы, возвраты за вчера и с начала месяца.
- Ozon: `/v3/finance/transaction/list` за вчера + `/v2/posting/fbo/list` — выручка, доставки, отмены.
- Формат: одна таблица WB / Ozon: выручка, заказы, средний чек, возвраты, реклама (если быстро доступно).

### ОПиУ за месяц
- WB: `reportDetailByPeriod` v5 по правилам скилла (задержка ~45 дней — показывать последний готовый месяц, предупреждать).
- Ozon: `/v3/finance/transaction/list` с разнесением операций по правилам `ozon-seller-api` (строка «НЕ РАСПРЕДЕЛЕНО» обязательна).
- Итог: единая таблица строк ОПиУ по обеим площадкам + суммарная прибыль.

### Юнитка
- Ozon — только по модели из `ozon-seller-api` (средний тариф логистики, выкуп из истории, налог 8%, реклама 10% если не задано). WB — из отчёта реализации по факту.

### Цены и реклама
- WB: `discounts-prices-api` list, изменения через `upload/task` (цены в копейках!). Реклама: `adv/v1/promotion/count`, расходы `adv/v1/upd` (может быть пустым).
- Ozon: `/v5/product/info/prices`, реклама через `ozon-performance-api` (ДРР = расходы/выручка).
- Изменение цен или ставок рекламы — только после явного подтверждения Босса с diff до/после.

## Правила

- Токены никогда не выводить в чат/логи; читать из Настройки соответствующей таблицы.
- Google-токен живёт ~1ч: перед серией запросов к Sheets/Apps Script обновлять через refresh_token.
- WB 429 → backoff 3s×(n+1), максимум 5 попыток. 204 = пусто, не ошибка.
- Задержка данных WB ~45 дней — всегда называть реальный период цифр.
- Числа сверять перекрёстно (заказы vs финансы), при расхождении >5% — флажить.
- Результаты кэшировать в `memory/cache/marketplace/*.json` с датой; старше 12ч — обновлять.

## Автоматизация (по отдельному решению Босса)
Через automations: ежедневная сводка утром, еженедельный ОПиУ. Создавать только после явного «да» от Босса.
