# OpenClaw Workspace - Automated Backup

## Repository

- **URL:** https://github.com/frutskoi/openclaw-workspace
- **Branch:** master
- **Remote:** origin

## Backup Scripts

### Manual Backup
```bash
~/workspace/scripts/backup-simple.sh
```

### Automated Backup (Cron)
```bash
# Add to crontab for automated backups every 6 hours
0 */6 * * * ~/workspace/scripts/backup-simple.sh >> ~/.openclaw/workspace/.backup.log 2>&1
```

## What's Backed Up

✅ **Configuration:**
- Agent configuration (AGENTS.md, SOUL.md, USER.md, IDENTITY.md)
- Skills and scripts
- Google Workspace integration code
- Documentation (README.md, BACKUP.md)

❌ **Excluded (.gitignore):**
- Google OAuth tokens (google-creds/)
- Memory files (memory/*.md)
- Session data (.openclaw/)
- Python cache files

## Quick Commands

```bash
# Check backup status
cd ~/.openclaw/workspace && git status

# Manual backup
cd ~/.openclaw/workspace && git add -A && git commit -m "Backup: $(date -u)" && git push origin master

# View last commit
cd ~/.openclaw/workspace && git log -1 --stat
```
